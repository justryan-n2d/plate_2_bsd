# Editable CAD drawings

Store reviewed, editable DXF master files here.

The first planned drawing is phase1_site_base.dxf, generated from site/phase1_traverse_coordinates.csv by scripts/generate_site_base.py.

The DXF has not yet been generated or inspected in a CAD application. Model-space units must be metres. The actual parcel outline must use courses 1-2 through 4-5 plus the adjusted P5-1 closing course. The original P5-1 and diagnostic gap are reference data, not extra boundary segments.
