# DWG delivery copies

Place converted DWG delivery files here after the source DXF has been checked.

DWG files are converted outputs, not the primary source of truth. After conversion:
1. Open the DWG in compatible CAD software.
2. Check geometry, dimensions, text, layers, and units against the reviewed DXF.
3. Inspect dimensions and plotting settings for conversion changes.
4. Fix issues in the source data or generator, then regenerate and reconvert.

No DWG file is claimed as complete yet. This README keeps the destination folder tracked until a reviewed file exists.
