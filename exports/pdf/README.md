# PDF exports

Place reviewed PDF drawing sheets and print/review documents here.

Before committing a PDF, check:
- sheet size and orientation match the assignment, including A3 drawing sheets where required;
- selected plot scale is correct and readable;
- dimensions, labels, linework, north arrow, legends, and title-block information are present;
- no drawing content is clipped or unexpectedly scaled;
- dimensions and drawing content agree with the source calculations and CAD files.

PDFs do not replace the editable DXF masters. Keep preliminary exports clearly identified.
