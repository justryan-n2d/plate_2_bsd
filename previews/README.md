# Drawing previews

This folder holds SVG previews generated by the drawing scripts from the same source geometry used for DXF files.

The existing Phase 1 source preview is site/phase1_site_base.svg. It remains there to preserve current links and avoid an unnecessary duplicate.

The generated preview is now produced by GitHub Actions at phase1_site_base_preview.svg and passes automated XML, coordinate-projection, vertex-count, and note checks. It is included with the DXF in the [successful workflow artifact](https://github.com/justryan-n2d/plate_2_bsd/actions/runs/38008699847), but is not yet committed as a repository file. Manual visual inspection remains pending.

SVG previews are for browser inspection. They do not prove CAD units, print scale, survey accuracy, or code compliance.
