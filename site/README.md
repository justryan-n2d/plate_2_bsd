# Phase 1 Site Base Files

This folder contains preliminary outputs for the lot-and-site-base phase of CE 393 Plate No. 2.

- phase1_site_base.svg: editable vector sketch. It intentionally displays the traverse closure gap.
- phase1_traverse_coordinates.csv: course bearings, distances, calculated latitude and departure, local endpoint coordinates, and a separate closure-gap row.
- phase1_site_analysis.md: known site conditions and outstanding questions.

## Important status

The five listed courses produce a linear misclosure of about 4.0120 m. The assignment also mentions both a 5.0 m existing barangay road and an 8.00 m road right-of-way. Do not force the traverse closed, change source values without confirmation, or treat the approximate 300.00 m² lot area as verified. Confirm both questions with the instructor before preparing the final site development plan.
